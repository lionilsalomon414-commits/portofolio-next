# Portofolio Cretivox (Next.js + GSAP)

Jalankan lokal:
  npm install
  cp .env.local.example .env.local   (isi URL API dari Postman)
  npm run dev                         (buka http://localhost:3000)

Deploy: push ke GitHub, lalu import repo di vercel.com.
Di Vercel, isi Environment Variables: NEXT_PUBLIC_API_BASE dan NEXT_PUBLIC_LOGIN_PATH.
